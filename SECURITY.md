# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues,
comments, or discussions.

Instead, use one of these private channels:

- **GitHub (preferred):** Click the "Report a vulnerability" button on the
  [Security tab](../../security/advisories/new).
- **Email:** Send details to neuroglow.dev@gmail.com.

Please include as much detail as possible: steps to reproduce, affected versions,
and any proof-of-concept code.

We will acknowledge receipt within 48 hours and work with you on a fix and
coordinated disclosure timeline.
